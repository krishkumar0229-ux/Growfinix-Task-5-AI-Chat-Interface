# Growfinix AI Chat Interface

An AI-powered chat interface built as part of the Growfinix AI Internship Task 5. The application provides a modern ChatGPT-style experience with real-time AI responses, streaming text, Markdown rendering, and loading states.

## 🚀 Features

- 💬 ChatGPT-style AI chat interface
- ⚡ Real-time streaming AI responses
- 📝 Markdown rendering
- 🔄 Loading/typing state while generating responses
- 🆕 New Chat functionality
- 📱 Responsive interface
- 🎨 Modern dark-themed UI
- 🔐 Secure API key management using environment variables
- 🧠 AI responses powered through OpenRouter
- 🔌 Vercel AI SDK integration
- 🖥️ React-based frontend
- ⚙️ Express.js backend

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- CSS
- React Markdown

### Backend
- Node.js
- Express.js
- CORS
- Dotenv

### AI
- Vercel AI SDK
- OpenRouter API
